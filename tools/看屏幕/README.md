# 看屏幕 · OCR 版

**让你的 AI「读」到屏幕上写了什么。**

不是看图——是认字。没有视觉模型，没有多模态，就是 OCR。

---

## 它能做什么

```
✓ 「屏幕上写了什么」      → 答得准
✓ 「你那个报错是什么」    → 认得出来
✗ 「我在干什么」          → 只能靠文字猜
✗ 「这界面长什么样」      → 完全不知道
```

**这就是它和「视觉模型」的区别。** 别指望它看懂画面，它只认字。

---

## 怎么跑

**就一步：双击 `开始.bat`。**

```
第一次：自动装依赖（约 100 MB，慢一点）
以后：  直接开始识别
```

它会自己做完三件事：

```
[1/3] 找 Python（PATH 里没有就翻常见安装位置）
[2/3] 检查依赖（没有就自动装，三个镜像轮着试）
[3/3] 开始识别
```

**前提：你机器上得有 Python 3.10 以上。**

没有的话它会告诉你去哪下，装的时候**记得勾 `Add Python to PATH`**。

要停：关掉那个黑窗口，或者 `Ctrl+C`。

## 产物

**`ocr.json`** —— 别的程序读它就能「看见」：

```json
  "lines": [

    "第 2 行文字",
    "..."
  ]
}
```

## 接进你自己的 bot

核心就一句：**读 `ocr.json`，把 `lines` 拼成一段话，塞进提示词。**

```js
// Node 侧
const fs = require('fs')
const OCR = '你的路径/ocr.json'

function readScreen() {
  try {
    const d = JSON.parse(fs.readFileSync(OCR, 'utf8'))
    if (Date.now() / 1000 - d.t > 30) return ''   // 超过 30 秒不用
    return '【你现在看到的屏幕】\n' + d.lines.join('\n')
  } catch { return '' }
}
```

**三个细节**：

1. **判断新旧** —— `t` 是时间戳，超过 30 秒就当没数据，别拿昨天的屏幕当现在的
2. **限行数** —— 本工具已经限到 60 行 / 1600 字，别自己再加
3. **别写元描述** —— 不要「以下是屏幕内容」这种，直接给文字，模型读得懂

Python 侧同理：

```python
import json, time

def read_screen(path='ocr.json', max_age=30):
    try:
        d = json.load(open(path, encoding='utf-8'))
        if time.time() - d['t'] > max_age:
            return ''
        return '【你现在看到的屏幕】\n' + '\n'.join(d['lines'])
    except Exception:
        return ''
```

---

## 三个坑

**① 全屏文字全塞会吃掉几千 token**

本脚本已经限到 60 行 / 1600 字。想改就改 `screen_ocr.py` 开头的 `MAX_LINES` / `MAX_CHARS`。

**② 认字会错**

「小鲸鱼」可能认成「小辣鱼」，「暴喵AI管家」认成「暴道AI管」。**不影响理解大意，但别指望逐字准确。**

**③ 实际是每 8~10 秒一次，不是 2 秒**

截图 0.1 秒，认字要 5~8 秒。`INTERVAL` 只控制两次识别之间歇多久。

想快就调小 `MAX_LINES`——认的字少了就快。

## 为什么不用视觉模型

试过 **Qwen2.5-VL-3B**（本地）：

| | OCR | Qwen2.5-VL-3B |
|---|---|---|
| 耗时 | 0.3 秒 | **6.7 秒** |
| 显存 | 0 | **7 GB** |
| 能说「他在打游戏」 | ❌ | ✅ |
| 能读准具体文字 | ✅ | ⚠️ 会出错 |

**7 GB 显存换「能猜出在干什么」，打游戏的时候不划算。**

两者可以并存——OCR 一直在跑，要问「我这界面长什么样」的时候再调 VL。
